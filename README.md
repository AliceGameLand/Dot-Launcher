# 귀염뽀쨕도트 런처

귀염뽀쨕도트 마인크래프트 런처입니다.
Microsoft 계정 로그인과 게임 자동 설치·업데이트를 지원합니다.

## 개발

Node.js 22를 사용합니다.

```powershell
npm ci
npm start
```

Windows 빌드: `npm run dist:win -- --publish never`
